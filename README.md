# Traditional Chinese Medicine Promotion System

## Project Overview

Traditional Chinese Medicine Promotion System is a web-based platform designed to promote traditional Chinese medicine knowledge and improve public awareness of herbal medicine and healthcare practices.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## System Modules

### User Module
- User Registration
- User Login
- Profile Management

### Medicine Information Module
- Browse Medicine Information
- Search Medicine Information
- Medicine Details

### Article Management Module
- View Articles
- Search Articles
- Category Management

### Admin Module
- Manage Medicine Information
- Manage Articles
- Manage Users

## Database

Main Tables:
- users
- medicines
- articles
- categories
